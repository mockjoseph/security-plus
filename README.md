## Overview

I am creating this repository with **two main goals**.

1. **The first** being that as of **August 31st 2026** I am using this repository to compile my notes to help review for the CompTIA Security Plus exam that I intend to take in the beginning of September.
2. **The second goal** is that I hope that anyone that stumbles across this repository can use compiled notes and references to help them also study for the Security+ exam.

> **If you are seeing this note then that means the repository is still in development and there will be new items coming in.**

I intend to add all notes that I have taken and some small mini-projects so that people can see hands on exercises for the topics that are covered in the exam.

All notes and contents will be relevant to the **SY0-701 Exam** that was released in 2023. For any new versions of the exam, I can not confirm that these notes will be comprehensive to pass the exam but will still be good reference for anyone getting involved with Cybersecurity or even just want a security background for their engineering development.

All notes and contents found in this are derived from **open source knowledge and information**. I have not and will not be paying and adding notes or content from training courses you have to pay for, or questions from practice exams you have to pay for from any party.

## Repository Structure

The structure of this repository maps well to how Professor Messer structured his training course. The exam is said to be split into **5 sections** with questions correlating to any given section.

With this, the repository will be split into **5 separate directories** where you will be able to see compiled notes and and coding examples for the technical aspects.

> **Note:** From my studying, there is no coding questions on the exam, but knowing concepts is never enough in practice so knowing how to implement the exams concepts will ideally help immensely to all of us learning.

## Exam Structure and Overview

| | |
|---|---|
| **Duration** | 90 minutes |
| **Questions** | Maximum of 90 questions |
| **Passing Score** | **750** on a scale of 100–900 |

### Exam Contents

| Domain | % of Exam |
|---|:---:|
| **1.0** – General Security Concepts | `12%` |
| **2.0** – Threats, Vulnerabilities, Mitigations | `22%` |
| **3.0** – Security Architecture | `18%` |
| **4.0** – Security Operations | `28%` |
| **5.0** – Security Program Management and Oversight | `20%` |

### Question Format

Questions are mostly multiple choice, or some form of it:

- Complete a task
- Fill in blank
- Generic multiple choice
- Drag and drop
- etc.

A list of certification objectives can be found on CompTIA website: [comptia.org](https://www.comptia.org)
